| 项目 | 结果 |
| --- | --- |
| Java / Spring Boot | Java 27、Spring Boot 4.1.1 编译及运行通过 |

## 验证结果

### 后端

执行 `cd backend && ./mvnw clean test`，**11 项集成测试全部通过**。使用 Testcontainers 独立 PostgreSQL，覆盖：

- 实际数据库健康检查及 Flyway 迁移。
- 只统计、展示已发布且交付可用的案例。
- 关键词、分类、免费/付费筛选和分页排序。
- SQL 注入式输入、百分号和下划线作为普通搜索文本处理。
- 付费详情只有预览，正文接口返回 403；直接调用受限 Mapper 也不能读取付费正文。
- 草稿、下架、暂停交付及不存在案例无法通过详情或正文接口读取。
- 非法参数的 400 响应、错误码和请求追踪编号。
- 下架后立即停止公开访问。
- 大整数 ID 按字符串返回。
- 数据库价格约束。
- 不存在的接口及不支持的方法返回结构化错误。

包和 XML 重命名后清理了旧构建产物，最终结果来自干净构建。未以关闭注解处理或移除 Lombok 作为最终解决方案。

### 前端

`generate:api`、`format:check`、`lint`、`typecheck`、`build` 均通过。

Playwright **14 项测试全部通过**，每个流程在桌面和手机各执行一次：

1. 从真实数据首页进入免费案例，读取完整教程。
2. 关键词、分类、阅读方式组合筛选及清除筛选。
3. 翻页保持筛选条件。
4. 空结果和非法查询提示。
5. 付费预览不包含私有正文，并验证 Java 正文接口拒绝访问。
6. 不存在案例的提示和返回入口。
7. 开发同域代理到 Java 的真实数据库健康检查。

测试复用本地 3000 端口前端，使用本机 Chromium；浏览器执行路径通过环境变量指定，未写入仓库。

另以临时生产前端指向不可用的 Java 地址，验证首页、列表和详情都显示重试提示，不返回伪造案例。临时故障验证进程已停止，正常开发服务不受影响。

### 视觉检查

已查看 1440px 桌面与 390px 手机下的案例列表、免费详情、付费详情截图。页面无横向溢出，筛选控件、正文、说明区和返回入口可用。截图仅用于本地验证，不进入业务资源库。
