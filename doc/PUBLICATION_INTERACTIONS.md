# 文章互动、动态与分享地址

- `GET /api/v1/publications/{id}/interaction` 和文章卡片聚合返回点赞、收藏、分享、阅读数量及当前账号互动状态。
- `POST /api/v1/publications/{id}/view`：页面可见且停留五秒后提交 UUID token。服务端按账号（匿名时按浏览器 token）每半小时去重；阅读试读计入访问，不代表完整阅读。浏览量不是独立访客数。
- `POST /api/v1/publications/{id}/share`：需登录；明确点击分享按钮或分享渠道时确认，悬浮预览不计数。每个账号对同一篇文章复用一条授权，服务端按授权 ID 唯一计数；重复点击、复制、刷新或并发确认均不会增加次数。统计表示发起分享的账号数，不代表成功送达。客户端自行生成的 token 无效。
- `GET /api/v1/home/activity?size=12`：需登录；只返回可见已发布文章的点赞、收藏、分享动态，阅读记录和匿名分享不公开。重复 PUT 不生成动态，取消点赞/收藏不删除曾发生的互动动态。昵称由身份端口批量读取，SQL 不跨身份领域。
- 当前点赞/收藏数量由关系表计算，阅读/分享数量由 V17 事件表计算；写入由文章行锁及事件唯一约束共同保证去重。

## 分享域名

项目根目录 `.env.example` 统一约定环境变量：

```dotenv
SITE_URL=http://localhost:3200
```

生产环境替换为完整 HTTPS 域名，例如 `https://community.example.com`。变量由后端运行环境注入，对应 `app.site-url`。本地 IntelliJ BackendApplication 的环境变量、PowerShell 启动环境或部署平台应配置此值；仅编辑根目录 `.env` 不会自动使 JVM 读取，需要启动器加载。正式域名变更后重启后端即可，前端无需重新构建。

`POST /api/v1/publications/{id}/share-link` 需要登录，验证文章已发布后创建或复用该账号对这篇文章的授权，返回 `/s/{token}` 独立分享链接。token 由服务端生成，含 256 位随机信息；前端不拼接域名、不使用普通文章地址。后端启动时验证 URL 必须为 http/https 网站域名。

## 单篇分享授权

- `/s/{token}` 展示分享人和封面，免费文章或当前账号已解锁的付费文章直接展示全文；未解锁的付费文章仅展示试读与登录／解锁提示。旧 `/s/{token}/read` 重定向到同一个分享地址。
- `GET /api/v1/shares/{token}` 返回分享预览与当前账号可否阅读全文；`/content`、`/media/{fileId}/url`、`/attachments` 每次校验令牌绑定文章、发布状态和素材绑定。封面和公开试读素材允许预览，私有正文素材与附件跟随全文权限。
- 免费文章可凭此令牌匿名阅读全文及下载该文章附件；令牌不写入全局登录 Cookie，不授权首页、探索或其他普通文章页面。普通 `/publications/{id}/content` 始终要求登录。
- 付费文章必须登录且该账号存在 `content_unlocks` 权益记录。分享不赠送解锁权益；积分购买流程暂未开放，不提供假解锁按钮。
- 下架或删除文章会使分享阅读失效。

首页轮播每六秒切换，鼠标悬浮、键盘焦点、隐藏页面或系统减少动态效果时暂停。无真实数据时展示空状态，不生成模拟互动。

分享面板支持悬浮预览封面与摘要、二维码、微信扫码、QQ 分享、复制及系统分享。二维码在浏览器本地生成；分享页显示分享者头像与公开评论，评论作者头像由身份目录批量签发。匿名评论操作回跳当前分享链接，发表评论需要登录。
