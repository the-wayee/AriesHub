# 运营后台与内容创作

AriesHub 是由主理人持续发布 AI 实践内容的付费社区。案例、学习文章、课程都是 Publication；价格采用整数积分，FREE 为零，CREDIT 大于零。课程现在可按二/三级标题组织章节目录，独立章节、课程进度与权益由后续应用用例建立。

## 页面与真实能力

| 页面 | 作用 |
| --- | --- |
| `/admin` | 成员、内容、评论、解锁总数，近七日注册/发布/评论，草稿与审核入口 |
| `/admin/publications` | 搜索、按状态/类型/价格筛选、分页、编辑、发布与下架 |
| `/admin/publications/new`、`/[id]` | 富文本创作、素材、发布设置、预览与保存 |
| `/admin/users` | 昵称/邮箱搜索、状态筛选、分页、停用与恢复；管理员受保护 |
| `/admin/comments` | 跨线程评论审核、隐藏评论、锁定讨论 |
| `/admin/analytics` | 真实七日活动、积分内容数、余额与实际扣减汇总 |
| `/admin/credits` | 只读实际积分流水与变动后余额 |

数据来自 PostgreSQL，不使用模拟收入、活跃或充值金额。活跃成员定义为最近七天发生过登录；注册/发布/评论按数据库日期汇总。后台 API 统一需要 ADMIN，普通成员返回 403，匿名返回 401；停用普通成员会立即撤销其已有登录态。

## 创作与素材

正文支持标题、粗体、斜体、列表、引用、代码块、链接、图片、视频与附件。TipTap 可视化编辑与 Markdown 源码切换，正文按 Markdown 持久保存。公开预览独立编辑。草稿允许正文/预览/交付说明尚未填写，但仍需要标题、摘要和所属主题；文章地址在首次保存后按 ID 自动生成；发布必须有完整正文，已发布内容不允许改为空正文。

既有草稿修改后五秒自动保存，手动保存与 Ctrl/⌘+S 始终可用；发布状态的修改需要显式保存。自动保存期间继续写作，按请求快照标记保存，后续输入保持待保存。保存失败不清空输入，离开内部链接可选择保存、放弃或继续编辑；刷新/关闭由浏览器提示。尚未创建的内容先手动保存，生成持久 ID 后进入自动保存。浏览器历史后退仍应先保存重要修改。

封面存文件 ID，内嵌素材存 `media:UUID`，展示时获取五分钟签名，定期刷新。上传正在进行时阻止保存/发布；编辑器本身阻止继续插入并显示上传状态。素材授权和尺寸规则见 [对象存储](OBJECT_STORAGE.md)。免费正文素材可公开；积分正文的私有素材当前锁定，封面和公开预览素材可公开。

## 后续开发边界

当前实现运营精选标记和公开排序优先，不代表个性化推荐算法。积分流水和解锁统计读取已经存在的数据库事实；发放积分、幂等扣减、购买解锁及支付仍需 credit 应用用例，不能通过后台任意改余额。聊天、推荐算法、充值订单/支付回调、独立课程章节与学习进度尚未接入。

下一阶段顺序：真实内容详情/阅读器与评论 → 积分发放、余额/流水、幂等解锁、付费正文与素材权益 → 收藏/阅读进度 → 运营推荐及聊天 → 充值支付。支付成功只增加积分，不直接授予内容权益。

## 验证

后端使用实际 PostgreSQL/Redis Testcontainers 验证后台权限、真实统计、成员停用、空正文草稿、素材引用回滚、封面移除及积分正文素材保护。前端 Playwright 同时覆盖桌面与手机，验证格式编辑、定价、预览、保存/发布、上传封面及内嵌图片/视频/附件、自动保存失败保留输入、离开保护与成员确认弹窗。


文章地址不接受编辑输入，规范链接 `/publications/{id}`；内部旧 slug 不可通过保存请求修改。新建和编辑请求不包含 slug。公开 ID 详情已接入后端真实内容；旧 slug 只提供读取兼容和重定向，静态概念稿明确标识。

素材显示实际网络传输进度与后端处理阶段，100% 不表示处理完成；取消中断请求，重试重新选择文件。服务端校验、素材绑定与签名授权仍属于内容用例，通用存储工具不承担文章业务。

### OSS 上传任务进度

每次上传携带独立 `uploadId`，通过 `GET /api/v1/admin/media/uploads/{id}` 读取 Redis 中当前账号的短期任务。后端按 OSS 成功确认的 5 MiB 分片累计 `loaded/total`，分片重试不增加进度；全部字节确认后进入 `FINALIZING`，合并与登记成功后才是 `COMPLETED`。任务隔离到 owner，十分钟过期，取消接口使用 DELETE；通用文件工具仅传递字节回调，不管理内容业务任务。

Next 默认转发缓存只有 10 MiB，开发转发显式对齐 Java 的 101 MiB 请求上限，避免截断视频与大附件；开发转发超时延长为十分钟，避免默认 30 秒在 OSS 处理中断开。生产网关必须对应配置请求大小与等待时间。真实 OSS 验证可显式设置 `ARIESHUB_OSS_LIVE_TEST=true` 并运行 `S3MultipartLiveTest`；测试创建独立诊断对象并在结束时删除，默认回归不访问云存储。
